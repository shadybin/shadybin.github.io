The review prompt

This is the brief Claude reviews every release with, exactly as shadybin sends it, loaded live from its source. The code under review follows it in each request, between digest-carrying markers, and the answer comes back as structured findings.

A verdict doesn't rest on this text alone. It follows by a fixed rule from the answers: a unit that fails, a malicious finding, or a capability left unexplained rejects the release. See Deciding in the spec.
